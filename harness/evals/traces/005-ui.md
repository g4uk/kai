# 005: ui — React SPA (login, job list, submission, results) + web serving layer

## Prompt

Build the end-to-end user-facing SPA for kumite-analyzer: a React app with four
screens (phone+OTP login, job list, new-analysis submission form, and per-job
results) that talks to the existing OTP-auth and jobs API entirely through
same-origin `/api/*` calls, relying only on the `HttpOnly`/`Secure`/
`SameSite=Strict` session cookie (never `localStorage`/`sessionStorage`), plus
a new `web` Docker Compose service that builds the production bundle and
serves it via nginx, reverse-proxying `/api/*` to the `api` service so the SPA
and API share one origin. Client-side auth-state detection uses a dedicated
`GET /auth/me` liveness endpoint (204/401) rather than any resource-scoped
call. Any 401 from any endpoint clears client state and redirects to login,
and the results screen renders every participant's metrics generically (no
hardcoded metric names) with distinct pending/done/failed states.
